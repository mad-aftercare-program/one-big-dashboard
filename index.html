Set up the live connection

Five steps, about ten minutes
  1. Create a new Google Sheet called Aftercare Dashboard Data. Results and settings are saved here.
  2. In it, open Extensions, Apps Script. Delete what is there and paste in the whole of Code.gs.
  3. At the top, set ACCESS_KEY (everyone who can view) and ADMIN_KEY (only you) to long passwords, and paste the master sheet ID into MASTER_ID.
  4. Run setup and allow access. Then Deploy, New deployment, Web app: Execute as Me, Who has access: Anyone. Copy the link.
  5. Paste the link and keys into box 2 and tap Sync now.

Links to share

These links open the dashboard already connected to the sheet, so people see live numbers without any set-up. They contain the access key, so share them only with the people who should see the data.

Activity log

Every time the dashboard reads from the sheet (pull), writes to it (push), or the sheet updates its saved copy by itself (automatic). "Sheet" rows come from the Sync log tab, "This device" rows are what this browser did.

A new project (for example Job placement) gets its own section with no coding. Add its numbers to the Projects tab of the master sheet. Each project name becomes a menu item, with tiles, a chapter table and a month-by-month table.

How to add a project

  1. Open the master sheet and go to the Projects tab.
  2. Add one row per number: Project, Metric, Chapter, Month (like 2026-11), Value, and Target if you have one.
  3. Tap Sync now in Data and sync. The project appears below and in the menu.

Target is for the whole programme for that month. A row with Chapter left empty or set to All is a programme-wide number.
